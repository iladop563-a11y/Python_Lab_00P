Python Lab OOP
Тема роботи
Проектування та реалізація об'єктно-орієнтованих систем в Python з використанням класів і спадковості.
Мета роботи
Набути практичних навичок проектування та реалізації об'єктно-орієнтованих систем мовою Python, використання класів, наслідування, інкапсуляції, поліморфізму, абстрактних класів, композиції та паттернів проектування.
Виконані завдання
Класова ієрархія з наслідуванням та поліморфізмом.
Інкапсуляція, property та контроль доступу.
Магічні методи та перевантаження операторів.
Абстрактні класи та композиція.
Реалізація паттерну проектування Strategy.
Файли репозиторію
Python_Lab_OOP.py — вихідний код лабораторної роботи.
README.md — опис лабораторної роботи та інструкція запуску.
.gitignore — файл виключень для Python.
Вимоги
Для виконання програми необхідно мати встановлений Python 3.
Сторонні бібліотеки не використовуються.
Інструкція запуску
Завантажити або клонувати репозиторій.
Відкрити папку з проєктом.
Запустити файл Python_Lab_OOP.py.
Запуск через командний рядок:
python Python_Lab_OOP.py
Після запуску програма послідовно демонструє результати виконання всіх п'яти завдань лабораторної роботи.
